# Следующая игра

Учебный сайт о видеоиграх. Автор: Аладашвили Илья Гиоргиевич, ВИС23, ДГТУ.

## Запуск
Распакуйте архив целиком и откройте index.html в браузере. Для одинаковой работы избранного на всех страницах рекомендуется запускать сайт через локальный HTTP-сервер или GitHub Pages. Например: `python -m http.server 8000`, затем открыть http://localhost:8000.

## Страницы и функции
- index.html — главная страница и тематические подборки.
- catalog.html — 12 игр, поиск, фильтры по жанру, настроению и режиму, сортировка, избранное.
- about.html — описание проекта.
- sources.html — ссылки на источники и правообладателей изображений.

games.js содержит данные. app.js отвечает за интерактивность. styles.css — оформление и адаптивность. assets/ — изображения игр. Интернет нужен для загрузки шрифта Google Fonts и переходов на внешние сайты; при отсутствии шрифта используется Arial.

Избранное хранится в localStorage текущего браузера. Регистрации, серверной базы данных и синхронизации между устройствами нет. Это учебный каталог, не магазин. Жанры и настроения — редакционная классификация.

## Проверка
Проверены страницы при ширинах 320, 390, 768 и 1440 px; поиск, фильтры, сортировка, сброс, избранное после перезагрузки, окно описания и мобильное меню. На физических мобильных устройствах не проверялось.

## Размещение
В отдельном публичном репозитории GitHub разместите содержимое этой папки в корне. В Settings → Pages выберите Deploy from a branch, ветку main и / (root). После завершения развёртывания GitHub покажет публичный адрес. Не загружайте только ZIP: Pages нужны распакованные файлы.

## Источники
Обложки и кадры взяты из официальных карточек игр Steam. Полный список — sources.html. Права принадлежат соответствующим правообладателям. Описания написаны для учебного проекта. В презентации для сравнения интерфейсов использованы снимки https://store.steampowered.com/search/?l=russian и https://itch.io/games от 30.10.2026.
